# nvim-configs

My [neovim](https://neovim.io/) configuration files.


# plugins

| plugin | purpose |
| --- | --- |
| [lazy.nvim](https://github.com/folke/lazy.nvim) | plugin manager |
| [nvim-lspconfig](https://github.com/neovim/nvim-lspconfig), [mason.nvim](https://github.com/mason-org/mason.nvim), [mason-lspconfig.nvim](https://github.com/mason-org/mason-lspconfig.nvim) | language servers setup and installation |
| [nvim-treesitter](https://github.com/nvim-treesitter/nvim-treesitter) | syntax highlighting and parsing |
| [conform.nvim](https://github.com/stevearc/conform.nvim) | code formatting |
| [telescope.nvim](https://github.com/nvim-telescope/telescope.nvim) | fuzzy finder for file search, grep, etc. |
| [gitsigns.nvim](https://github.com/lewis6991/gitsigns.nvim) | git diff markers and hunk actions |
| [which-key.nvim](https://github.com/folke/which-key.nvim) | keybind hints menu  |
| [todo-comments.nvim](https://github.com/folke/todo-comments.nvim) | highlight **TODO**/**NOTE**/**FIXME** comments |
